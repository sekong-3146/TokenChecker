# TokenChecker

TokenChecker는 ChatGPT Work/Codex와 Claude Code의 구독 사용량을 Windows 시스템 트레이에서 확인하는 로컬 유틸리티입니다.

## 요구 사항

- 실행 환경: Windows 10 22H2 x64 이상
- 개발/빌드 환경: .NET SDK 10.0.400
- 선택한 종류의 Codex CLI 또는 Claude Code가 설치되어 있어야 합니다. 계정 로그인은 설정창에서 진행합니다.

## 계정 설정

1. 트레이 아이콘을 오른쪽 클릭하고 **설정**을 엽니다.
2. 확인할 에이전트에서 Codex 또는 Claude를 골라 **추가**합니다. 합계 최대 4개이며, Codex 4개나 Codex 3개 + Claude 1개처럼 자유롭게 구성할 수 있습니다.
3. 각 행에 구분할 이름을 입력하고 **로그인**을 눌러 브라우저에서 원하는 계정으로 로그인합니다.
4. **저장**을 누르면 해당 계정들의 사용량을 확인합니다. 사용 체크를 끄면 일시 중지하고, 제거하면 확인 대상에서 제외합니다.

로그인 중에는 **로그인 취소**로 중단할 수 있습니다. 실패하거나 취소하면 기존 계정 설정을 유지합니다. 설정창의 **취소**는 저장하지 않은 변경을 버립니다.
기존 설정은 Codex·Claude 기본 CLI 계정으로 유지됩니다. 설정창에서 다시 로그인하면 TokenChecker 전용 계정으로 전환됩니다.

## 사용량 창

트레이 아이콘을 왼쪽 클릭하면 사용량 창이 화면 오른쪽 아래(작업 표시줄 위)에 열립니다. 다시 클릭하면 닫힙니다.

- **새로고침**: 창 오른쪽 아래의 새로고침 아이콘을 누릅니다.
- **고정**: 핀 아이콘을 누르면 다른 창을 눌러도 닫히지 않고 항상 위에 표시됩니다. 고정한 채 종료하면 다음 실행 때 창이 다시 열립니다.
- **크기 조절**: 창의 왼쪽 변, 위쪽 변, 왼쪽 위 모서리를 끌어 크기를 바꿉니다. 오른쪽 아래는 고정되며 최소 크기(300x170)보다 작아지지 않습니다.
- 크기와 고정 상태는 자동으로 저장됩니다.

설정창에서 다음을 바꿀 수 있습니다.

- **표시 모니터**: 창을 띄울 모니터를 고릅니다. `자동`이면 클릭한 화면에 뜹니다. 선택한 모니터가 연결되어 있지 않으면 클릭한 화면에 뜹니다.
- **창 투명도**: 0%(불투명)부터 80%까지 조절합니다. 슬라이더나 숫자를 바꾸는 동안 사용량 창에 바로 반영되며, 저장하지 않고 닫으면 원래 값으로 돌아갑니다.

## 요금제 표시

각 계정의 한도 바 위에 요금제를 표시합니다. 정보가 없거나 목록에 없는 값이면 **확인 불가**로 표시합니다.

- **Codex**: 조회 응답의 `planType`을 사용합니다. `prolite`는 **Pro 100**, `pro`는 **Pro**로 표시합니다.
- **Claude**: 해당 계정 CLI 로그인 정보의 `subscriptionType`을 사용합니다. Max 요금제는 같은 파일의 `rateLimitTier`에서 배수를 읽어 **Max 5x**처럼 표시합니다. 이 값은 로그인할 때 기록되므로, 요금제를 바꾼 뒤에는 설정창에서 다시 로그인해야 새 값이 반영될 수 있습니다.

Codex Pro 계열(`pro`, `prolite`) 계정은 **주간 한도만** 보여줍니다. 툴팁과 트레이 아이콘도 일반 Codex의 주간 한도를 사용하며, Spark의 별도 한도를 섞지 않습니다. Codex Plus와 Claude 계정 등 나머지는 5시간·주간 표시를 유지합니다. 이는 앱의 표시 규칙이며 서비스 정책을 단정하는 의미는 아닙니다.

## Claude 로그인 유지

설정창에서 로그인한 TokenChecker 전용 Claude 계정은 로그인 토큰이 만료되기 전에 앱이 자동으로 갱신합니다. 기본 CLI 계정은 Claude Code가 직접 갱신하므로 앱이 건드리지 않습니다.

갱신이 서버에서 거부되면 재시도하지 않고 **로그인 필요** 상태로 멈추며, 설정창에서 다시 로그인해야 합니다. 로그인 파일을 잠깐 읽지 못한 경우는 일시 오류로 처리하고 다음 주기에 다시 시도합니다.

## 빌드

저장소 루트에서 실행합니다.

```powershell
dotnet build TokenChecker.sln -c Release
dotnet test TokenChecker.sln -c Release
```

## 게시

.NET 런타임이 설치되지 않은 Windows x64에서도 실행할 수 있는 단일 파일을 생성합니다.

```powershell
.\publish.ps1
```

출력 파일: `artifacts\publish\TokenChecker.Tray.exe`

## 파일 위치

앱 데이터는 다음 경로에 저장됩니다.

- `%LOCALAPPDATA%\TokenChecker\settings.json`
- `%LOCALAPPDATA%\TokenChecker\usage-cache.json`
- `%LOCALAPPDATA%\TokenChecker\diagnostics.log`
- `%LOCALAPPDATA%\TokenChecker\accounts\<계정 ID>\codex`
- `%LOCALAPPDATA%\TokenChecker\accounts\<계정 ID>\claude`

## 보안

- 새 계정의 로그인 정보는 각 CLI가 위 계정별 폴더에 저장합니다.
- 전용 Claude 계정의 토큰을 갱신할 때, 앱은 그 계정 폴더의 `.credentials.json`에서 access token, refresh token, 만료 시각만 다시 씁니다. 나머지 내용은 그대로 둡니다.
- 기본 CLI 계정의 로그인 파일(`%USERPROFILE%\.claude`, `%USERPROFILE%\.codex`)은 읽기만 하고 쓰지 않습니다.
- 토큰은 설정 파일·사용량 캐시·진단 로그에 기록하지 않습니다.
- 계정 제거와 설정 취소는 확인 대상만 변경합니다. 이미 생성된 계정별 로그인 폴더를 자동 삭제하지 않습니다.
- 텔레메트리를 보내지 않습니다.
- 모델 생성 요청을 보내지 않습니다.

## 제한

- 브라우저에서 실제 계정 인증을 완료해야 사용량을 조회할 수 있습니다. 같은 종류의 계정도 각각 로그인해야 합니다.
- Claude 사용량 조회와 토큰 갱신은 공개 문서에 없는 엔드포인트를 사용합니다. Claude Code가 업데이트되면 동작하지 않을 수 있습니다.
- 한 번 **로그인 필요**나 **권한 오류**가 되면 수동 새로고침으로는 풀리지 않습니다. 설정창에서 다시 로그인하거나 앱을 다시 시작해야 합니다.
- 갱신한 토큰을 파일에 저장하지 못한 상태에서 앱을 종료하면 그 계정은 다시 로그인해야 합니다.
